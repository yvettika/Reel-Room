## How to use one

1. Film it. Phone upright, say the script once all the way through, then repeat the hook line two or three more times. Reel Room picks the best take of each part.
2. Skip anything in (parentheses) when you talk. Those are notes for Reel Room about what to show on screen.
3. In Claude Code, type `/reel`, drag in your clip, and give it the script file, for example: `use scripts/01-missed-call.md as the script`. Reel Room reads the notes and builds the graphics around them. Lines starting with `#` (title, hook, style) are ignored as speech.
